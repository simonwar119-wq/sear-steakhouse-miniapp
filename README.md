# Sear Steakhouse MiniApp 🥩

> SEAR STEAKHOUSE 会员积分微信小程序

SEAR STEAKHOUSE 官方会员小程序。支持扫码积分、会员等级、消费记录查询等功能，提升餐厅会员体验。

## ✨ 功能

- 📱 扫码积分 — 扫描消费小票自动积分
- ⭐ 会员等级 — 多级会员体系
- 📊 积分记录 — 查看历史积分和消费明细
- 🎁 积分兑换 — 积分兑换菜品和优惠券
- 🏪 餐厅信息 — 菜品展示、门店导航

## 🛠 技术栈

- 微信小程序原生框架
- 微信云开发 CloudBase
- Cloud Functions Node.js

## 🔐 安全说明

本仓库不应提交以下内容：

- 真实手机号、私人邮箱、内部地址
- 微信云环境密钥、服务端密钥、数据库连接信息
- `.env`、`.key`、`.csv`、导出的会员数据
- 真实生产环境配置截图

生产环境信息请放在微信开发者工具、本地环境变量或云端 Secret 中。
