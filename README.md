# Sear Steakhouse MiniApp 🥩

> SEAR STEAKHOUSE 会员积分微信小程序

天津 SEAR STEAKHOUSE（瑟尔牛排馆）官方会员小程序。支持扫码积分、会员等级、消费记录查询等功能，提升餐厅会员体验。

## ✨ 功能

- 📱 扫码积分 — 扫描消费小票自动积分
- ⭐ 会员等级 — 金卡/黑卡/钻卡多级会员体系
- 📊 积分记录 — 查看历史积分和消费明细
- 🎁 积分兑换 — 积分兑换菜品和优惠券
- 🏪 餐厅信息 — 菜品展示、门店导航

## 🛠 技术栈

- 微信小程序原生框架
- 微信云开发 (CloudBase)
- Cloud Functions (Node.js)
